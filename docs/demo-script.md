# 演示脚本（demo-script.md）—— 8 分钟完整业务闭环

前置：后端已启动（`python run.py`，可选先跑 `python scripts/seed.py`）；支付宝开发者工具已导入 `frontend/dist/build/mp-alipay` 并关闭域名校验。

多角色说明：单台模拟器用「我的 → 演示工具」切换账号即可；有条件可用「多开模拟器」各自登录不同账号，实时性（WS 推送）演示效果最佳。

---

## 0. 注册与实名（1 分钟）

1. 首次打开小程序自动静默登录（mock 账号）
2. 广场任意操作 → 弹「需要实名认证」→ 去「我的」提交姓名/证件号 → 徽标变「已实名」
3. 演示未实名拦截：切换一个未实名新账号 → 访问广场 → 403 引导弹窗

## 1. 发起组队（1 分钟）

1. 队长账号 → 广场页右下角「+ 发起」悬浮按钮 → team-create 页
2. 填写：队伍名「周五晚火锅局」、目标人数 4、品类火锅、菜单、时间选明天 → 「创建并发布」
3. 跳转队伍详情：状态「招募中」，进度 1/4，邀请码已生成

## 2. 招募与并发抢名额（1.5 分钟）

1. 队员 a1、a2 依次从广场点卡片报名 → 队长端实时看到成员增加（WS）
2. 队长踢人演示：把 a2 移出 → a2 收到「被移出队伍」通知 → a2 重新报名（复活式重加入）
3. 队长「关闭邀请」→ a3 用邀请码加入 → 403「队长已关闭链接邀请」→ 队长重新打开（或跳过此步）

## 3. 自动成团 + 建群（1 分钟）

1. 最后一名队员报名瞬间：全员收到「队伍已成团」通知；状态跳「已成团」；报名端点立即 409
2. 点「进入群聊」：可见 system 欢迎消息；队员发消息、队长回复，两端实时同步
3. 演示防跑路：队长在详情页点解散 → 409（成团后禁止解散）

## 4. 到店核销 → 账单生效（1.5 分钟）

1. 各账号进入「核销 / 账单」页，用「我的核销码」逐个核销，头像点亮
2. 只核销部分时账单恒「待生效」；队长录入总额 300
3. 最后一人核销瞬间 → 账单变「已生效」：人均 ¥100，3 条独立支付记录（队长补差保证 Σ=总额）

## 5. 独立结算 → 归档（1 分钟）

1. 每人点「我来结账」→ 模拟支付动画 1s → 已支付；支付广播实时刷新他人视图
2. 最后一人支付瞬间 → 账单「已结清」、队伍「已完成」归档，不可再操作

## 6. 异常路径（1 分钟，可选）

1. 新建一局成团后只部分核销 → 队长「核销异常？解散重开」→ 账单作废、队伍 failed → 自动跳复制出的新草稿
2. 演示超时提醒：把某 formed 队伍 dining_time 改到 3 小时前（改库或等定时器）→ 队长收 checkin_reminder

---

备注：所有页面按 375px 移动视口设计；未实名用户被全站拦截并引导至「我的」页完成实名。
