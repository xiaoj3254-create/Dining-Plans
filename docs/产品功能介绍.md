# 约饭组队智能 Agent 系统 · 产品功能介绍

> 一句话：把「约饭」这件事从**一个个问人、凑人、算钱**的琐碎过程，变成一次**发起 → 自动凑齐 → 自动建群 → 到店确认 → 各自结账**的顺畅体验。全程由规则驱动的 Agent 自动调度，不需要人工协调。

---

## 一、我们解决什么问题

想吃饭却凑不齐人，是日常高频但很难解决的痛点：

| 现实困境 | 本产品的解法 |
|---|---|
| 想吃的馆子人多才划算，一个人去不划算 | 发布饭局 → 广场招募，随时看还差几人 |
| 一个个私聊问朋友「周末有空吗」，效率极低 | 生成邀请链接 / 分享卡片，好友点开即报名 |
| 加群后还要反复确认时间地点、谁点菜 | 发起时定好**餐馆、时间、预选菜单**，报名前信息透明 |
| 有人临时不来，剩下的人怎么分摊？ | 到店确认后**按实际到场人数**分摊，缺席者不参与 |
| 陌生人拼桌怕信息泄露、怕被骚扰 | 全站脱敏展示（只露昵称/年龄/性别）+ 举报与拉黑机制 |

## 二、适用人群与角色

**三类角色，权责清晰：**

- **队长（发起人）**：填写饭局信息、指定餐馆与预选菜单、决定组队模式；拥有移出队员、关闭邀请、解散队伍等管理权限，并负责到店后录入账单总额。
- **队员**：从广场报名或点链接加入；可查看队内脱敏信息与饭局安排，可主动退出未成团的队伍；成团后进入专属群聊协商细节。
- **平台**：负责准入（实名校验）、秩序（内容安全、举报处理）与账务规则（分账口径、状态流转）的自动执行。

**准入要求**：所有用户需完成实名登记后才能浏览与报名，从源头保障线下见面的安全基线。

## 三、两种组队模式（核心差异化）

| | **匿名拼桌** | **链接邀请** |
|---|---|---|
| 适合场景 | 想认识新饭搭子、随机组局 | 和朋友约饭，顺便让陌生人补位 |
| 入队方式 | 仅约饭广场公开报名 | 广场报名 **+** 分享链接/邀请码直达 |
| 隐私口径 | 队内只可见年龄性别，入队后才能看到队友昵称，不提供个人主页 | 同样脱敏，熟人自行线下识别 |
| 额外管控 | 不支持邀请链接，杜绝私下拉人 | 仅队长可关闭邀请链接，防止恶意拉人 |

两种模式共用同一套状态机与结算规则，减少认知成本。

## 四、完整使用闭环（8 分钟可走通全流程）

```
① 实名登记 → ② 发起饭局 → ③ 广场招募 → ④ 自动成团 & 建群
   → ⑤ 到店确认 → ⑥ 账单生效 → 各自结账 → 归档
```

**① 实名登记** — 首次进入静默登录，未实名用户访问广场会被引导完成实名登记。

**② 发起饭局** — 选餐馆 → 勾选预选菜品 → 定人数与时间 → 选组队模式 → 发布。系统自动生成邀请码并上架广场。

**③ 广场招募** — 其他用户按模式/菜系/时段/距离筛选浏览，点卡片即可报名；队长端实时看到成员增加，可随时移出队员。

**④ 自动成团 & 建群** — **人数达到目标上限的瞬间，系统自动完成四件事**：关闭报名入口、状态切为「已成团」、创建专属群聊并拉入全员、推送通知给每个人。此后报名接口直接拒绝，避免超员。

**⑤ 到店确认** — 每位成员到店后在「核销与账单」页使用自己的确认码点亮到场状态；队长录入实际消费总额。

**⑥ 账单生效与结算** — **全员确认到场后账单自动生效**：按实际到场人数算出各自应付金额，生成独立支付单；每人独立结账、互不垫付；全部结清后队伍自动归档。

**异常兜底**：到店人数不足、有人爽约导致无法锁账时，队长可发起「解散重开」——原账单作废，系统一键复制原配置生成新草稿，改个时间就能重新招募。

## 五、功能清单

### 1. 发起约饭
- **选择餐馆**：内置餐馆库，支持按菜系筛选与名称/菜系/商圈搜索，展示餐馆图片、商圈、人均消费与简介。
- **预选菜单**：从所选中餐馆的菜单里勾选菜品（带菜品图片、价格、分类与「招牌/必点/辣/清淡」标签），形成本次饭局的点单参考。
- **自动带出**：选定餐馆后自动填好菜系与商圈，减少重复输入。
- **必填校验**：饭局名、人数、餐馆、菜系、时间逐项校验并给出字段级提示，缺项时发布按钮置灰。
- **目标人数**：滑块调人数，实时显示，最少 2 人。
- **组队模式**：单选项独立卡片呈现，说明文案随选择实时变化。

### 2. 约饭广场
- **两行筛选**：第一行模式单选（全部 / 匿名拼桌 / 链接邀请）；第二行菜系、时段、距离、排序横滑选择；**菜系与时段支持多选**（同维度取并集、跨维度取交集），并有「已筛选 N 项 / 清空」回执。
- **关键词搜索**：命中饭局名、菜系、商圈、餐馆名与菜单备注。
- **卡片信息**：状态、距离、剩余招募时长、餐馆名、就餐时间、人数进度条、模式标签；已满员或已截止的卡片自动弱化并禁用报名按钮。
- **浏览体验**：下拉刷新 + 上拉加载 + 图片懒加载，整卡可点进详情；右下角常驻「发起」悬浮按钮。

### 3. 组队与成员管理
- **报名 / 加入**：广场一键报名，或通过分享链接、邀请码直达加入。
- **邀请与分享**：生成小程序分享卡片，好友点开即携带邀请码进入；队长可随时关闭邀请链接。
- **队长管理**：移出队员（二次确认，被移出者收到通知，且可重新报名复活）；成团前可解散队伍；成团后禁止解散，防止发起人跑路。
- **退出**：队员可自由退出未成团队伍，名额自动释放并刷新广场。
- **成员列表**：显示脱敏后的昵称、年龄、性别与角色标签；队长可见移出操作，普通队员不可见管理按钮。
- **名额安全**：多人同时抢最后几个名额也不会超员——已在 10 人并发抢 2 个名额的压测中验证「绝不超卖」。

### 4. 自动成团与队伍群聊
- **自动成团**：满员瞬间自动关闭报名、切状态、建群、通知全员，无需任何人手动确认。
- **群聊**：成团后开放。成员可发文字与图片（如餐馆定位截图），支持消息撤回；队长可发「@全体成员」公告；顶部固定显示饭局名、餐馆与用餐时间，不必来回翻记录。
- **实时同步**：成员变动、状态变化、群聊消息通过实时推送同步到其他成员页面，无需手动刷新。

### 5. 到店确认与账单结算
- **到场确认**：每人一个确认码，到店后自助点亮；页面显示全员到场进度。
- **账单录入**：仅队长可录入或修改消费总额；未全员到场时账单保持「待生效」，允许异常调整。
- **自动生效**：全员确认的瞬间账单自动锁定，按**实际到场人数**算人均，给出每人应付金额。
- **独立结算**：每人独立支付自己那份，互不垫付、账目清晰；队长份额自动补差，保证分账合计等于账单总额。
- **结清归档**：全员付清后账单变为「已结清」，队伍归档进入历史。

### 6. 消息通知
- **类型化推送**：报名、成团、账单生效、解散、到店提醒等事件自动推送到「消息」页，按类型区分展示（类型图标 + 标题 + 正文 + 时间）。
- **未读提醒**：未读条目标红点并在底部 Tab 上显示角标数字。
- **可操作**：点卡片直达对应饭局；支持下拉刷新与逐条删除。

### 7. 我的
- **用户信息**：头像、昵称与实名状态标签一览。
- **对外资料**：昵称、年龄、性别；资料预览可看到「别人眼中的你」，一眼确认隐私边界。
- **实名登记**：提交后加密留痕，状态标签实时更新。
- **历史饭局**：查看已结束的饭局记录。
- **协议与合规**：用户协议与隐私政策全文页，同意记录留痕；支持账号注销。
- **演示工具**：一键切换测试账号，单台设备即可扮演队长/队员多角色，便于演示多端实时协作。

### 8. 餐馆与菜单库
- 内置 **16 家餐馆、96 道菜**，覆盖火锅、烤肉、日料、川菜、粤菜、西餐、快餐、素食八大菜系。
- 每家餐馆含图片、商圈、人均、简介与完整菜单；每道菜含图片、价格、分类与标签。
- 餐馆简介页独立成页，可从队伍详情直接点入；底部「以此为餐馆发起饭局」一键带入发起流程。

### 9. 安全、风控与隐私
- **脱敏铁律**：任何对外展示的用户信息只有昵称、年龄、性别三项，姓名、证件、手机号等一律不出现在接口响应中，并有自动化测试逐条扫描全部接口响应。
- **非成员不可见**：成团后的队伍信息仅成员可见，陌生人只能看到招募中的公开信息。
- **举报与拉黑**：可举报违规用户、拉黑不想再遇到的人；被拉黑者无法再加入你的饭局；被举报累计达阈值自动限制相关账号。
- **内容安全**：群聊与文本输入经过内容过滤，违规内容被拦截。
- **操作可追溯**：关键管理操作（踢人、解散、账单修改等）留有审计记录。
- **频率保护**：接口有限流保护，防止恶意刷报名、刷举报。
- **年龄与证件校验**：需年满 18 周岁，证件号做格式与校验位检查。

### 10. 体验规范（贯穿全站）
- **视觉统一**：紫色主色；状态色标准化——蓝=进行中、绿=已完成、灰=已失效、红=危险操作、浅橙=注意事项。
- **有效 / 失效口径**：只要还能参与或正在进行（含已成团未有人到场）一律保持白底高亮可点；只有已结束或已取消的条目才做灰度弱化。
- **反馈到位**：所有可点元素有按压反馈；请求期间统一显示加载态并置灰按钮防重复提交；列表底部有收尾提示；横滑内容有溢出箭头提示。
- **移动端适配**：底部固定操作栏与手势条安全区适配；键盘弹起时输入区域自动避让。

## 六、三个典型场景

**场景 A · 陌生人拼桌（周末想涮火锅，一个人不好点菜）**
发起「周六晚火锅局」，选火锅店、勾选毛肚虾滑、定 4 人匿名拼桌 → 发布到广场 → 半小时内凑齐 3 位陌生饭搭子 → 自动成团建群，大家在群里约到店时间 → 到店各自确认 → 吃完人均结账，互不相识但账目清爽。

**场景 B · 朋友约饭 + 陌生人补位（老同学聚会凑不满一桌）**
发起「同学聚会·粤菜早茶」用链接邀请模式 → 群里分享链接，5 位同学点开即入队 → 还差 1 人，允许广场陌生人补位 → 满员自动成团。

**场景 C · 工作日午餐搭子（午休时间紧张）**
午休前发起「今日快餐拼单」，选快餐店与套餐，定 2 人成团 → 满员即建群，直接约楼下集合 → 全程两分钟，不耽误午休。

## 七、当前版本边界（如实说明）

本版本为可完整演示的 MVP，以下能力为模拟实现或尚未接入：

- **支付**：模拟支付（点击即到账），未接入真实支付通道
- **实名**：完成的是本地格式与校验位校验并加密留痕，未接入权威实名核验服务
- **订阅消息**：高时效事件已入队排队，接入正式小程序 AppID 后即可推送
- **真机体验**：需正式 AppID 与 HTTPS 合法域名；本地开发在模拟器中直接可用
